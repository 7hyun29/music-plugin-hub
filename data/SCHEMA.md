# plugins.json 형식 (확정 v1)

파일은 `{ "version": 1, "plugins": [ ... ] }` 형태. 플러그인·Kontakt 라이브러리 하나가 항목 하나.
형식 검사는 `./smoke.sh`로 한다.

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `id` | 문자열 | O | 영문 소문자·숫자·하이픈, 중복 불가. 예 `kontakt-8` |
| `name` | 문자열 | O | 표시 이름 |
| `vendor` | 문자열 | O | 제조사 |
| `version` | 문자열 | | 스캔으로 채움 |
| `type` | 문자열 | O | 아래 목록 중 하나 |
| `formats` | 배열 | O | `VST3`, `VST2`, `AU`, `AAX` 중 여러 개. Kontakt 라이브러리는 빈 배열 `[]` |
| `locations` | 배열 | O | `windows`, `mac` 중 하나 이상 (설치된 컴퓨터) |
| `license` | 문자열 | | 관리 계정 이름만. 예 `iLok`, `Native Access`. 시리얼 금지 |
| `tags` | 배열 | | 자유 입력. 예 `스트링 편곡`, `게임 BGM`, `VEP용` |
| `note` | 문자열 | | 직접 쓴 한 줄 소감 |

`type` 목록: `오케스트라 라이브러리`, `Kontakt 라이브러리`, `신스`, `샘플러`, `EQ`, `컴프`, `리버브`, `유틸`, `기타`

## 결정 기록 (2026-11-25)
- Kontakt 라이브러리는 같은 목록에 넣고 `type`으로 구분
- 설치 위치는 Windows / Mac 2칸. Logic·VEP 중 어디서 쓰는지는 필요하면 태그·메모로
- 태그는 자유 입력. 대신 smoke.sh가 띄어쓰기·대소문자만 다른 태그(`게임BGM` / `게임 BGM`)를 경고로 알려줌
